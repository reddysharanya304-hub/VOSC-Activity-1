
# 🎮 Tic-Tac-Toe Game | VOSC Activity-1

## 📌 About the Project

This project is a modern and interactive Tic-Tac-Toe game developed as part of VOSC Activity-1.

Tic-Tac-Toe is a two-player game where players take turns marking X and O on a 3×3 grid. The player who successfully places three symbols in a horizontal, vertical, or diagonal row wins the game.

## 🚀 Technologies Used

- HTML5 – For creating the game structure.
- CSS3 – For styling and responsive design.
- JavaScript – For game logic and functionality.

## ✨ Features

- Interactive 3×3 game board.
- Two-player gameplay (Player X and Player O).
- Automatic winner detection.
- Draw detection.
- Player turn indicator.
- Scoreboard to track player wins.
- Restart game functionality.
- Reset scores functionality.
- Modern dark theme with attractive colors.
- Responsive design for different screen sizes.

## ▶️ How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Double-click the index.html file.
4. The game will open in your web browser.
5. Start playing!

## 🎯 How to Play

1. The game starts with Player X.
2. Player X selects an empty box.
3. Player O takes the next turn.
4. Players continue taking turns.
5. The first player to get three symbols in a row wins.
6. If all nine boxes are filled without a winner, the game ends in a draw.
7. Click "Restart Game" to play another round.
8. Click "Reset Scores" to clear the scoreboard.
